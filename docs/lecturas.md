# Catálogo de lecturas

Historias que ya conoces, contadas enteras en **simple present** o en **simple past**.
Marca con `[x]` las que quieres usar. Cada línea dice el **momento concreto** que se
contaría, porque el unidad no es la serie entera sino una escena.

Reglas de la v1:

- Cada lectura es **una sola historia en un solo tiempo**. Nunca se mezclan tiempos.
- El bloque de lectura son 2-3 líneas, y solo el bloque que lees queda oscuro.
- Sin ejercicios ni preguntas: es lectura.
- Retelling original: se cuentan los hechos con palabras nuevas, nunca se copia
  diálogo ni texto de las fuentes.
- Cada serie se escribe en las dos versiones (presente + pasado) para poder ver
  el contraste.

Leyenda: `P` = versión en presente, `T` = versión en pasado.
